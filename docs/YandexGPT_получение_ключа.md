# Памятка: получить ключ YandexGPT (для бота)

Чтобы бот считал запросы клиентов через YandexGPT (российский провайдер, оплата в
рублях, данные в РФ), нужно один раз получить **два значения** и передать их нам:

1. **API-ключ** сервисного аккаунта (строка вида `AQVN...`);
2. **ID каталога** (folder_id, вида `b1g...`).

Провайдер в боте уже реализован — нужен только ключ.

---

## Шаг 1. Аккаунт и оплата
1. Войти в консоль: **[console.yandex.cloud](https://console.yandex.cloud)** (нужен
   аккаунт Яндекса; для бизнеса можно оформить на организацию).
2. Создать **платёжный аккаунт** (привязать карту или для юрлица — оплата по счёту).
   Новым пользователям обычно дают пробный грант.

## Шаг 2. Узнать ID каталога (folder_id)
1. В консоли откроется облако с каталогом по умолчанию (часто называется `default`).
2. Зайти в каталог → на странице обзора скопировать **«Идентификатор»** — это
   `YANDEX_FOLDER_ID` (например `b1gxxxxxxxxxxxxxxxxx`).

## Шаг 3. Сервисный аккаунт
1. В каталоге: меню → **«Сервисные аккаунты»** → **«Создать сервисный аккаунт»**.
2. Имя — любое, например `ekrom-bot`.
3. Назначить роль **`ai.languageModels.user`** (право пользоваться YandexGPT).
   Можно на уровне каталога.

## Шаг 4. API-ключ
1. Открыть созданный сервисный аккаунт → вкладка **«API-ключи»** →
   **«Создать API-ключ»** (тип: для доступа к API, можно указать область
   `yc.ai.languageModels.execute` или оставить общий).
2. **Скопировать секрет сразу** — он показывается один раз. Это `YANDEX_API_KEY`.

## Шаг 5. Передать нам
Пришлите по защищённому каналу два значения:
- `YANDEX_API_KEY` = <секрет API-ключа>
- `YANDEX_FOLDER_ID` = <идентификатор каталога>

Дальше мы:
- пропишем в `.env`: `LLM_PROVIDER=yandex`, `YANDEX_API_KEY=…`, `YANDEX_FOLDER_ID=…`
  (модель по умолчанию — `yandexgpt-lite`, самая дешёвая);
- перезапустим бота и проверим качество разбора на реальных запросах.

---

## Сколько это стоит
YandexGPT Lite ≈ 0.2 ₽/1000 входных и 0.4 ₽/1000 выходных токенов. Одно сообщение
клиента ≈ 0.3–0.4 ₽. Ориентир: **10 000 сообщений/мес ≈ 3 600 ₽**. Снимает потолок
бесплатного Groq (~130–180 сообщений/сутки).

## Замечание
Если качество разбора на Lite окажется хуже — можно переключить модель на
`yandexgpt` (Pro) одной строкой в `.env` (`LLM_MODEL=yandexgpt`), это дороже в ~5 раз,
но всё ещё копейки на нашем объёме.
